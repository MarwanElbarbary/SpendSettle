## 🚀 About

**SpendSettle** is a full-stack financial management web application that helps users manage personal money and shared expenses in one place.

The project originally started as a small **OOP Digital Wallet project**, but I decided to take it further and transform it into a complete production-ready web application instead of stopping at a simple GUI or academic task.

---

## ✨ Features

- 💳 Digital Wallet
- 💸 Deposit, Withdraw & Money Transfers
- 📊 Personal Expense Tracking
- 🎯 Monthly Budget Management
- 👥 Shared Expense Groups
- 🧾 Bill Splitting
- 🤝 Debt Settlements
- 🔐 PIN-Protected Wallet Balance
- 📜 Transaction History & Receipts
- ☁️ MongoDB Atlas Cloud Database
- 🚀 Live Production Deployment

---

## 👥 Shared Expenses

Create groups for trips, friends, roommates, family, or any shared expenses.

Bills can be split using:

- Equal Split
- Exact Amounts
- Percentages

SpendSettle automatically calculates **who owes whom** and allows users to settle debts directly through their wallets.
